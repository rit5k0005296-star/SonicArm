## 参数与选模

比较学习率1e-4/3e-4、BatchNorm统计量更新/冻结四组。选中lr0.0001_freezeBNTrue，第29轮。AdamW，weight_decay=1e-4，batch32，cosine最多80轮，早停18轮。CE加权重0.15的温度2蒸馏用于保护旧模型（温度只用于训练损失，推理不缩放logits）。

每轮加权采样1024条：新板上40%、前批板上20%（其中65%分配给1-2）、旧真人15%、合成25%（其中一半分配给unknown/silence）。板上训练侧每条额外4个轻度速度0.94–1.06、增益变化增强。固定划分后生成增强。

选模先最大化新验证正确数，并惩罚前批板上、旧真人正确数下降及合成非指令误触发增加；再比较新/旧验证真实标签CE，不使用测试结果。没有为了分数更高而忽略错误类别。

## 板上运行

解压到新的文件夹，进入该文件夹运行：

```bash
python3 tc_resnet_infer_wav.py /实际路径/1-1-1.wav
```

依赖numpy、scipy，无需PyTorch。脚本读取同目录model_weights.npz、preprocess_config.json、label_map.json。必须把这几个文件整体替换，不要沿用旧npz。PC也可运行`python inference.py /录音路径.wav`，需PyTorch。

NumPy/PyTorch在电脑上对新旧板上共26条保留/回归录音逐条验证，Top1全部一致，最大logit绝对误差1.5974045e-05。尚未在真实ARM板上验证。execute固定false，没有机器人动作接口。

样本量小，分数未做概率校准；阈值需要板上unknown/silence独立验证。进一步提高1-1与复位，应补充新会话难例和背景声，再保留新的外部测试；不要把本次保留测试反复用于调参。
