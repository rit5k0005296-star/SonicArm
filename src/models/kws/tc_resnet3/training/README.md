## 数据审计与防泄漏

ZIP共40条M4A，按父目录1-1、2-1确定类别，原文件名保留。没有执行压缩包内任何文件。安全解压到工作区后用FFmpeg解码为16kHz单声道；按用户说明归类为板上来源。实测文件时长2.645–3.499秒，活动区间1.620–2.590秒，全部适配5.2秒窗口，无需截断。

本批未检出相同/近似完全相同的波形副本；与旧735条真人作PCM哈希和下采样归一化相关检测，重叠数0。不能由此断言没有所有近重复。文件夹标签作为真值，未人工逐条听辨。40条均参与梯度训练，不留新验证或测试。旧437条训练录音继续回放，原149条验证用于选参，原149条测试只作历史回归；所有增强都在训练侧生成。真人总计775条：477训练、149验证、149历史测试。

## 训练参数与选择依据

六组候选：1e-4/3e-4分别冻结或更新BatchNorm统计量，补充冻结BatchNorm的3e-5/5e-5。补充小学习率的依据是前四组训练/验证表现存在新录音拟合和旧验证正确数的取舍，未依据测试结果挑选参数。v4也保留为验证候选。选中lr5e-05_freezeBNTrue，第6轮。

AdamW，weight_decay=1e-4，batch32，最多80轮，余弦退火、早停18轮，每轮加权采样1280条。采样权重：新静园35%、旧板上20%、其他真人25%、合成20%；合成权重一半分配unknown/silence，各域内按类均衡。新录音每条生成7个训练增强，旧真人每条额外2个增强，速度0.93–1.07、增益-3至2dB、受限位移和轻度25–35dB合成噪声；配合轻度时频掩蔽。

损失为交叉熵加权重0.15的教师蒸馏。蒸馏温度2只用于训练，推理温度仍为1。选参先最大化历史验证正确数（板上加倍，惩罚合成非指令误判增加），再比较新训练录音正确数，最后比较历史验证交叉熵与新训练交叉熵。因为本批没有验证集，其中新数据项是训练指标，不冒充验证结果。

合成非指令unknown/silence共40条，原始误判为指令：3 → 3。不代表现场误触发率，仍缺真实板上非指令录音验证。旧回归录音已在历轮开发中观察过，不能宣称是外部独立测试。

## 整包上板

解压到新的TCResNet_Jingyuan_v5文件夹，并整包使用，避免旧npz和新pth混用。板上无需PyTorch，依赖NumPy、SciPy，输入WAV：

```bash
python3 tc_resnet_infer_wav.py /实际路径/录音.wav
```

支持4秒和5秒WAV，统一对齐补零到5.2秒。M4A先转为16kHz单声道WAV，或在电脑上使用需PyTorch/FFmpeg的`python inference.py /路径/录音.m4a`。模型只输出分类，execute保持false。

本机对新训练40条加旧真人回归149条，共189条逐一核对NumPy/PyTorch：Top1全一致，最大logit绝对误差0.00037193298，真实类别分数最大差2.3245811e-06。未在真实ARM板上测速度或数值。下次现场另录未参与训练的新会话语音，才能判断泛化效果。
