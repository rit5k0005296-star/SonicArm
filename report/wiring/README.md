# SonicArm 系统总体接线与通信示意图

文件：

- `SonicArm_系统总体接线与通信示意图.svg`：可编辑矢量源图。
- `SonicArm_系统总体接线与通信示意图.png`：汇报/文档用位图。
- `assets/`：用户提供的 PYNQ-Z2、显示屏、有线耳机麦克风、Arduino Nano 类控制板和机械臂实物图。

图中证据边界：

- 实线蓝色：当前已经实现或已由用户板端观察验证的通信链路。
- 橙色虚线：UART 机械臂控制设计链路；当前 FPGA-10 `app.py` 仍处于 `dry_run`，未打开或发送机械臂串口命令。
- 红色：各设备独立供电。
- 黑色虚线：UART/控制信号共地要求。

当前未确认并在图中保留为待核信息：Arduino 具体型号、UART 引脚、逻辑电平、波特率、动作帧协议、机械臂/舵机额定电源。
